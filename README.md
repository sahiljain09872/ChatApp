# **Real-Time Chat Application**

## **Overview**

This is a **real-time chat application** built with **React, Node.js, Express, MongoDB, and Socket.io**, with **Google Cloud integration** for enhanced scalability and performance. It supports **one-to-one and group chats, real-time notifications, text and file sharing**, and **room-based communication**.

## **Features**

- 🔹 **One-to-One & Group Chat** – Seamless communication for users.
- 🔹 **Real-Time Notifications** – Instant updates on new messages.
- 🔹 **File Sharing** – Share images, documents, and other files.
- 🔹 **Room-Based Chat** – Create and join rooms using unique Room IDs.
- 🔹 **Secure & Scalable** – Optimized for performance and user security.
- 🔹 **Future Enhancements** – Adding **voice & video calling**.

## **Tech Stack**

### **Frontend:**

- React.js
- HTML, CSS, JavaScript

### **Backend:**
